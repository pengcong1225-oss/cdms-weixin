# 体脂秤轮测测试患者数据 runbook

本 runbook 只定义测试环境的受控数据准备和核对步骤。不得在小程序启动、前端测试或发布流程中自动执行；实际执行必须由授权操作者在数据库备份完成后单独进行。

## 执行前备份与停止条件

1. 记录操作者、执行时间、环境、目标机构和备份文件的绝对位置/校验摘要。
2. 在 `cdms` 数据库和 `cdms-iot` 数据库分别完成可恢复备份；未能验证备份可恢复时停止。
3. 按身份证查询测试患者，身份证已存在时必须核对姓名；按手机号查询时若手机号属于其他身份证，立即停止。
4. 精确核对测试患者2的 patient id、手机号和目标机构；任一身份证、手机号、主键或机构不一致，立即停止。
5. 查询目标机构是否已有相同 `device_ref` 的 `ACTIVE` 绑定；若存在，立即停止，不自动释放、抢占或覆盖。
6. 所有 ID 以字符串保存和比对；禁止转换为 JavaScript `Number`，禁止把原始身份值写入普通日志、URL 或埋点。

## 幂等写入范围

### 测试患者

- 复用已锁定主档案，不创建 `cdms_patient_account`，不伪造微信身份。
- 仅幂等补齐 COPD 专档、一次高危 COPD-SQ、一次状态为已确诊的诊断记录，以及少量非手环随访/评估数据。
- 已有明确标记的同类测试记录时更新/复用，不重复叠加。
- 不写 `cdms_device_binding`、`cdms_device_measurement`、`cdms_patient_monitor_status`、`cdms_monitor_alert`、IoT 上传批次或任何手环记录。

### 测试患者2

- 只把姓名更新为“测试患者2”，并同步更新明确标记的筛查冗余姓名。
- 将 CDMS/IoT 关联记录的机构字段迁移到 `1972545374712086529`；除机构字段外不删除、重置、伪造或重算原记录。
- 保留 `cdms_patient_account`、微信关联、所有设备绑定、设备测量、监测状态、告警、IoT 上传批次、手环测量/日汇总/会话及来源审计字段。
- 迁移前后比较手环记录主键集合、设备绑定主键集合和关键指标内容摘要；集合或摘要不一致时停止并回滚。
